# 仕様

## 目的
出演したライブのセットリストを記録し、「どの曲を何回・いつ演奏したか」をすぐ確認できるようにする。
データは本人だけが見られる。

## 利用者
- 本人（自分のアカウント 1 つ）
- 審査用のデモアカウント（サンプルデータ入り。README に記載）

新規登録画面は作らない。アカウントは Supabase ダッシュボードで作成し、ダッシュボードの Auth 設定で新規登録（Allow new users to sign up）を無効にする。

## 画面

### ログイン `/login`
- メールアドレス・パスワードでログイン
- 失敗時は「メールアドレスかパスワードが違います」
- ログイン済みなら `/` へ移動

### 曲一覧 `/`（要ログイン）
- 自分が演奏した全曲を表示：曲名／演奏回数（回数に比例したバー）／最後に演奏した日
- 並び替え：演奏回数順（既定）・最近やった順・曲名順
- 曲名で絞り込み検索
- 曲をタップすると、その曲を演奏したライブ（日付・ライブ名・会場）を新しい順に展開
- ヘッダーにライブ本数・曲数

### ライブ `/lives`（要ログイン）
- ライブをセトリ風カードで日付の新しい順に表示
- カードを開くと曲順どおりのセットリスト、編集・削除ボタン
- 「ライブを追加」で編集画面（モーダル）

### ライブ編集（モーダル）
- ライブ名（必須・100 文字まで）、日付（必須）、会場（任意）
- 曲の入力モードを切り替え：1 曲ずつ（並べ替え・削除可）／まとめて貼り付け（1 行 1 曲）
- 空行は無視。前後の空白は除去
- 保存は RPC `save_live` を 1 回呼ぶ
- 削除は確認ダイアログを出す

### 共通
- ヘッダーにログアウト
- 未ログインで要ログインのページに来たら `/login` へ

## 曲の同一判定
前後の空白を除き、英字の大文字小文字を無視して同じなら同じ曲（DB の `title_key` で判定）。
表記ゆれ（「ver.」違いなど）は別曲として扱う。

## やらないこと（今回の範囲外）
新規登録、パスワードリセット画面、曲の統合・名前変更、共有機能、画像添付
（README の「今後の改善」に書くと、設計の見通しを伝えられる）
